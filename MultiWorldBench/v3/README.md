# MultiWorldBench V3

V3 是独立基准定义，只包含十个高层指标。评分代码、Case 配置、ID、路径和验证流程均
位于 V3 自身目录，不导入其他 MultiWorldBench 版本的实现，也不读取其他版本的配置、
数据目录、来源清单或归档。

- 导航：控制隔离度、协同公平性、跨视角运动一致性
- 共享世界：共享状态同步性、跨视角结构一致性、空间推理能力、竞态条件一致性
- 回访：风格一致性、ID 一致性

导航的 180 个 Case 同时服务控制隔离度和协同公平性。每个“可见性 × 富几何地图”包含两个五例循环干预 family：一组固定 A 的完整五轮动作历史并遍历 B 的五种动作，另一组固定 B 并遍历 A。动作集合为静止、前进、后退、左移和转头；每例双方均覆盖全部五种动作。控制隔离度只使用目标角色历史固定的 family，比对另一角色不同动作下的目标相机响应，并取 A/B 两个方向的较低分。协同公平性按动作类别比较 A、B 的移动距离、路径长度、归一化轨迹偏离和航向变化分布。两项指标共享 Case 和位姿估计结果，但使用不同的分组方式。

共享状态同步性包含 3 个放置 Case 和 3 个摧毁 Case。放置逐帧判断行动成功、方块数量一致、作用位置一致、材质相同且符合预期，四项求和后除以 4；摧毁只判断前三项，求和后除以 3，不评价材质。两类均输出 0–1 分，并先分别汇总。

结构一致性使用无障碍转向 Case，只评价两个建筑身份问题，不包含朝向。空间推理能力使用遮挡—破坏—显现 Case，以遮挡移除、目标显现和建筑身份为门控，再评价分割面积与相机夹角。竞态条件一致性让 A、B 只在同一帧向同一位置各放置一次不同方块，评价生成双视角中的方块数量是否一致、类型是否一致，以及最终方块是否属于本例 A/B 候选材质；第三项同时输入两张标准方块参考图，不要求特定材质获胜，也不依赖 GT。回访中 A 静止、B 使用原生输入移动，
每次转场要求建筑至少连续 8 帧离开 B 的视野。实际采集和模型输出统一写入各 case 的
V3 相对输出路径。
